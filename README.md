✿ my projects

⋆˚✿˖°

> a collection of things i've made!

✦ 01. XDAM - independent artist website ✦

A website I created for an independent music artist to showcase his music and identity.

I took inspiration from old arcade games and CRT monitors to give the website a nostalgic, interactive feeling. I wanted visitors to feel like they were exploring something rather than simply scrolling through a page.

> **Built with:** HTML, CSS, JavaScript

✦ 02. Starlit Cafe - interactive cafe website ✦

A fictional cafe inspired by Rosalina from Super Mario Galaxy and cozy gaming environments. ✩

I wanted the website to feel welcoming and a little magical, so I included features like light and dark mode, an interactive menu, a guessing game, and a contact form.

> **Built with:** HTML, CSS, JavaScript


✦ 03. Starry Summit Lake Retreat - resort website ✦

A fictional resort website inspired by the Swiss Alps.

I used a dark navy and gold color palette to create a peaceful, starry atmosphere. This project focused more on organizing content, designing layouts, and creating a consistent visual experience.

> **Built with:** HTML, CSS

✿ currently working on

✧ Stellr — organization & focus website

My senior project! ♡

Stellr is a task management and focus website I'm creating to make staying organized feel a little less overwhelming.

The idea came from wanting a simple, friendly space where people can keep track of their responsibilities without feeling like productivity has to be stressful.

**Some features I'm working on:**

- ✧ Creating and managing tasks
- ✧ Recurring tasks and due dates
- ✧ A focus timer
- ✧ Tracking completed tasks
- ✧ Saving information with localStorage

**Built with:** HTML, CSS, JavaScript
